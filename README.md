## ✨ Project Highlights

* **Glassmorphism Design:** A modern, frosted-glass UI built entirely from scratch using CSS `backdrop-filter` and semi-transparent backgrounds.
* **Light & Dark Theme:** A fully functional theme toggle switch that seamlessly transitions the website between a deep space aesthetic and a bright holographic fluid aesthetic.
* **Live GitHub Graph:** Automatically fetches and displays my real-time GitHub contribution graph using a custom deep purple gradient and a built-in legend.
* **Fully Responsive:** Fluid grid layouts and flexible CSS that perfectly adapt to desktop, tablet, and mobile screens.
* **Interactive Elements:** Smooth scrolling, hover animations, a dynamic "Back to Top" button, and integrated FontAwesome iconography for a polished user experience.

---

## 🛠️ Technologies Used

* **HTML5:** Semantic structure and accessible layout.
* **CSS3:** Custom styling, flexbox layouts, media queries, glassmorphism, and transition animations.
* **Vanilla JavaScript:** DOM manipulation for the Light/Dark mode toggle and scroll detection logic.
